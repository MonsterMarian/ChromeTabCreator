# 🌐 Chrome Tab Creator (Tvůrce Chrome Kombinací Karet)

Moderní desktopová aplikace pro systém Windows, která umožňuje snadno vytvářet zástupce na Ploše pro Google Chrome s libovolnou kombinací více webových karet najednou.

## ✨ Klíčové funkce
- **Vlastní název zástupce:** Nastavte si jakýkoliv název pro novou sadu webů.
- **Vkládání URL:** Snadné přidávání a mazání odkazů + rychlá tlačítka pro oblíbené weby (Gemini, Claude, ChatGPT, GitHub, YouTube...).
- **Vynucený Dark Mode (`--force-dark-mode`):** Spuštění vybraných karet přímo v tmavém režimu.
- **Nové okno (`--new-window`):** Otevře vybrané karty v čistém samostatném okně Chrome.
- **Okamžitý test:** Tlačítko pro okamžité otestování vytvořené sady bez nutnosti ukládání.
- **Generování `.lnk` na Plochu:** Na jedno kliknutí vytvoří hotového zástupce s vlastní ikonou přímo na vaší Ploše.

## 🚀 Instalace a spuštění

```bash
git clone https://github.com/MonsterMarian/ChromeTabCreator.git
cd ChromeTabCreator
pip install -r requirements.txt
python app.py
```

## 🛠 Požadavky
- Windows 10 / 11
- Python 3.10+
- Google Chrome
